Place licensed font files in landing/assets/fonts/ :
  quincy-cf-text-regular.woff2, quincy-cf-text-medium.woff2   (Quincy CF Text - headings)
  circular-book.woff2, circular-medium.woff2, circular-bold.woff2   (Circular - body/buttons)
Until then the page falls back to Source Serif 4 (headings) and Figtree (body).

Optional (hero headline, weight 600): quincy-cf-text-semibold.woff2 (Quincy CF Text Semibold). Falls back to Medium/Regular if missing.

Circular: family name is "circular". Put circular-book / circular-medium / circular-bold with .woff2 (or .woff/.otf/.ttf) here, or install the font on the machine.

Optional (StemWave section title, weight 700): quincy-cf-text-bold.woff2 (Quincy CF Text Bold). Falls back to Semibold/Medium/Regular if missing.
